JARVIS.IR — نسخهٔ رایگان و ساده، بدون کلید API

این نسخه از OpenAI API استفاده نمی‌کند و برای پاسخ‌های ساده به کلید یا اعتبار API نیاز ندارد.
پاسخ‌های چت در مرورگر ساخته می‌شوند و قابلیت‌ها محدودند؛ این نسخه جایگزین یک مدل هوش مصنوعی پیشرفته نیست.
برخی مرورگرها قابلیت تشخیص گفتار را ندارند. خواندن پاسخ با صدای مرورگر در صورت پشتیبانی فعال می‌شود.

برای Render:
Root Directory: JARVIS_IR_ONLINE_CHATGPT_STYLE
Build Command: npm install
Start Command: npm start

اجرای محلی:
npm install
npm start
سپس http://localhost:3000
